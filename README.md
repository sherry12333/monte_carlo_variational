

# Variational Monte Carlo

## Overview

This project implements the Variational Monte Carlo (VMC) method for numerical studies of quantum systems.

The main idea is to combine the variational principle with Monte Carlo sampling to estimate the expectation value of the Hamiltonian for a chosen trial wave function. The variational parameters can then be adjusted to search for a lower-energy state.

## Methods

The project includes:

- Construction of a trial wave function
- Monte Carlo sampling of particle configurations
- Evaluation of the local energy
- Calculation of statistical averages
- Analysis of energy convergence
- Optimisation of variational parameters

## Purpose

The project was carried out as part of my computational physics studies and was intended to develop practical experience with:

- Monte Carlo methods
- Numerical integration
- Statistical sampling
- Quantum-mechanical modelling
- Numerical convergence and error analysis
